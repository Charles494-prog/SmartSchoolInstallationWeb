# SmartSchool – installation website

The public page that explains how to install **SmartSchool** (offline on a school network, or online on a web host).

- Static site: `index.html`, `assets/styles.css`, `assets/site.js`, `assets/logo.svg`. No build step.
- Light and dark mode, keyboard-accessible tabs, mobile-first.
- Host it anywhere that serves static files (GitHub Pages, Netlify, Vercel, any web server).

Preview locally:

```sh
python3 -m http.server 8080   # then open http://localhost:8080
```

The application itself lives at https://github.com/Charles494-prog/SmartSchoolWebsite.
