Choose how your school will use it

You pick this once, the first time you open SmartSchool. You can change it later from the Superadmin settings.

LAN (Offline)

One computer runs SmartSchool. Other devices open it over the school Wi-Fi.

Good for

  • Schools with slow or no internet
  • Fast set-up on one PC
  • No hosting costs

Keep in mind

  • No student or parent accounts – staff register students
  • Works only inside the school network
  • Reminders go to teachers

What you'll need

A Windows or Linux PC that stays on during school hours, and a Wi-Fi router everyone connects to.

Install for LAN

Online (Hosted)

SmartSchool runs on a web host. Everyone opens it from anywhere.

Good for

  • Parent and student accounts
  • Grades and alerts on phones at home
  • Email notifications

Keep in mind

  • Needs a web host and a domain
  • Monthly hosting cost
  • Someone should look after updates

What you'll need

A hosting plan that supports PHP 8.3+ and MySQL, a domain name, and an email account for sending notices (SMTP).

Install

Pick your setup. Each guide ends at the same place: the Create Superadmin page, followed by a short setup wizard.

SmartSchool Launcher for Windows
Windows 10 or 11 · 64-bit · includes everything it needs
Coming soon

  1. Download and open the launcher

    Run SmartSchool-Setup.exe. If Windows SmartScreen appears, choose More info → Run anyway.

  2. Choose “LAN (Offline)”

    The launcher checks the computer, creates the database and starts SmartSchool for you.

  3. Allow it through the firewall

    When Windows asks, tick Private networks and click Allow access. Without this, other devices can't connect.

  4. Open it on other devices

    The launcher shows an address like http://192.168.1.10:8000 and a QR code. Type it in any browser on the same Wi-Fi (we recommend Brave or Chrome), or scan the QR with a phone.

  5. Create the Superadmin and finish setup

    Enter your name, email and a strong password, log in, and follow the setup wizard (school name, school year, sections, staff accounts…).

Internet is not required in LAN mode, but every device must be connected to the same Wi-Fi or network as the computer running the launcher. Keep that computer on during school hours.

  1. Install the requirements

    On Ubuntu/Debian:

    sudo apt install php8.3-cli php8.3-sqlite3 php8.3-mbstring php8.3-xml php8.3-gd php8.3-zip php8.3-intl composer nodejs npm git

  2. Download SmartSchool

    git clone https://github.com/Charles494-prog/SmartSchoolWebsite.git smartschool
cd smartschool

  3. Start it

    The start script installs what's missing, prepares the database and shows the address to open.

    ./start-school.sh

  4. Allow the port on the firewall (if enabled)

    sudo ufw allow 8000/tcp

  5. Create the Superadmin and finish setup

    Open the address shown (for example http://192.168.1.10:8000) from any device on the same network.

A detailed guide comparing hosts (managed Laravel hosting, VPS with a control panel, and others), with verified prices and limits, is being prepared. The steps below work on any VPS.

  1. Get a server

    A small VPS (1–2 GB RAM) running Ubuntu with PHP 8.3+, MySQL and Nginx. You don't need the launcher online – the server runs the background jobs itself.

  2. Download and install

    git clone https://github.com/Charles494-prog/SmartSchoolWebsite.git smartschool
cd smartschool
composer install --no-dev --optimize-autoloader
npm ci && npm run build
cp .env.example .env && php artisan key:generate

  3. Connect the database

    Put your database name, user and password in .env, then run:

    php artisan migrate --force

  4. Point your domain to the public folder

    The web server's document root must be smartschool/public, not the project folder. This is the most common setup mistake.

  5. Turn on the background jobs

    Add one cron entry so backups, reminders and attendance rules run on time:

    * * * * * cd /path/to/smartschool && php artisan schedule:run >> /dev/null 2>&1

  6. Create the Superadmin and finish setup

    Open your domain, choose Online (Hosted), create the Superadmin and follow the setup wizard. Set up email (SMTP) there to turn on notifications and two-factor login.

Questions

Is SmartSchool free?

Yes, you can install and use it for your school. Hosting costs, if you choose Online mode, are paid to your hosting provider.

Does LAN mode really work without internet?

Yes. The main computer serves SmartSchool over your Wi-Fi. Phones and laptops only need to be on the same network. Email notifications need internet, so in LAN mode reminders are shown inside the app to teachers.

Why can't other devices open the address?

Check that they're on the same Wi-Fi as the main computer, that the firewall allows SmartSchool on private networks, and that you typed the exact address shown by the launcher (including :8000).

Can I move to a new computer later?

Yes. Export a backup from Settings → Backups on the old computer and import it on the new one. A safety backup is made before every import.

What about student privacy?

Student data is personal data of minors under the Data Privacy Act of 2012 (RA 10173). SmartSchool limits access by role and logs changes, but your school remains responsible for consent, retention and breach procedures. Review these with your data protection officer or a lawyer.
